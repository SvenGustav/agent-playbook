# Start here

Before reporting any task as complete, read `playbooks/03-verification-gates.md`. A
summary is a claim; the artifact is evidence.

Then pick the playbook for the work at hand.

- Planning a change: `playbooks/02-plan-then-delegate.md`
- Writing a reusable procedure: `playbooks/01-skills-as-procedural-memory.md`
- Reviewing your own work: `playbooks/04-review-loops.md`
- Scheduling work that must survive the session: `playbooks/05-durable-jobs.md`
- Long session with slow calls: `playbooks/06-context-budget.md`

Run `make lint` after editing a playbook.
